## B. 待依原廠修正（內容出入）

### B1. 黑名單 →「Deny Rules／Override Deny Rules」（最重要）
- Illumio **無「黑名單」功能**，本質為**白名單（allowlist）模型**。手冊「黑名單設定」應對應原廠 **Deny Rules**（25.2 起 Allow/Deny/Override Deny 皆支援 intra-/extra-scope），歷史上為 **Enforcement Boundaries**（24.2/25.2 起由 Deny rules 取代）。
- 全文保持「白名單優先、Deny 為疊加例外」的框架；勿把「黑名單」當成產品功能名。
- 依據：*Security Policy Guide 25.2 — Rules / Ways to enforce policy*。

### B2.「Overwrite Deny Rules」→「Override Deny Rules」（拼字）
- 原稿用語拼字錯誤，原廠正確名稱為 **Override Deny Rules**（優先序最高、不可被覆寫）。全文修正。

### B3. 強制模式俗稱
- 勿把 Selective／Full 標為「黑名單模式／白名單模式」；原廠名稱為 **Selective Enforcement／Full Enforcement**（同 Agent 手冊術語）。

### B4. Workloader 指令名稱
- 通稱 `workloader import` → 實際為 **`wkld-import`**。
- **無 `mode` 指令**；變更強制狀態經 `wkld-import --allow-enforcement-changes`。
- `label-dimension` → 實際為 **`label-dimension-export`**（及對應 import）。
- `delete` 為真實指令（對應 `deletehrefs`）。
- 認證：`workloader pce-add` 產生 `pce.yaml`；乾跑預設，加 `--update-pce` 才套用、`--no-prompt` 供自動化。
- 標準倉庫為 **github.com/brian1917/workloader**（Illumio Labs）。「自負風險／非核心 PCE」屬正確定性，但 README 無逐字免責聲明 → 如需引用請用 Illumio Community 文章，勿宣稱為 README 原文。

## C. 待你／實機／原廠登入頁確認
- `/var/lib/illumio-pce` 是否為必備備份物件：原廠未列；官方必備為 **政策＋流量兩個 DB dump ＋ `runtime_env.yml`**。請以實機／Support Portal 確認後再保留該路徑。
- Map 命名：25.2 現行工具為 **Map／Illumination Plus**，「Illumination」為舊稱（可接受，精確時註版本）。

`illumio-pce-ctl`（start/stop/restart/status -v/set-runlevel/cluster-status/cluster-members、runlevel 概念、`sudo -u ilo-pce`）；備份 `illumio-pce-db-management dump`（政策）與 `traffic dump`（流量、需 .tar.gz）、於跑 `agent_traffic_redis_server` 的資料節點執行、備份 `runtime_env.yml`；標籤 R/A/E/L 與自訂標籤類型；強制與可視為獨立控制；Map 草圖＝Draft View、Reported View；ruleset 三要素（scope／intra-scope／extra-scope）；Policy Generator（Intra/Extra/IP List）；變更需 Provision 才生效。
