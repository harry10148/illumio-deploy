## C. 待你／實機／原廠登入頁確認（未擅自定論）

| # | 項目 | 說明與建議 |
|---|---|---|
| C1 | RHEL 8 套件清單 | 原廠公開頁未內嵌，導向需登入的 Support Portal「VEN OS Support and Package Dependencies」，且隨版本變動。原稿清單合理，**請以目標 VEN 版本的該頁核實**後再視為原廠確認。|
| C2 | 抓封包程序 | `kill -USR2 [PID of platformhandler]`／`agent_signal.ps1 … SIGUSR2`／`illumio-ven-ctl.exe -action send_signal …` 在公開 22.2–25.x VEN 文件**查無逐字佐證**（現行 Troubleshooting 頁不含），歷來位於登入限定 KB。建議以實機 `illumio-ven-ctl --help`／Support KB 佐證；另 Windows 啟用用 `agent_signal.ps1`、停用用 `-action send_signal` 兩種介面不一致，建議統一。|
| C3 | `status health` 子指令 | 官方 `--help` 子指令清單只列 `status`（未列 `health`）。`status -v` 合理；`status health` 請以實機 `illumio-ven-ctl status --help` 確認。|
| C4 | AIX `/etc/rc3.d` 開機腳本 | 自動擷取時官網頁回 403，未能獨立確認；AIX 其餘（不支援 SecureConnect、須用 Illumio 版 IPFilter、勿動 genfilt/mkfilt）均已確認。|
| C5 | `activate` 設模式語法 | 若範例要附帶模式，原廠新語法為 `--enforcement idle|visibility_only|selective|full`（舊 `--mode illuminated|enforced|idle` 仍相容，**兩者勿並用**）；Windows 同義選項改單一連字號。|

## D. 原廠已確認無誤（重點）

通訊埠 8443/8444（地端）、443（SaaS）、TLS 1.2；心跳每 5 分鐘、漏 3 次進降級、連 3 次成功復原；離線預設伺服器型 60 分/端點型 24h；最小狀態每 4h 心跳、VTAP 停/啟；四個 VEN 程序（AgentManager / PlatformHandler / VtapServer / AgentMonitor）名稱、角色、執行身分（root / LOCAL SYSTEM）；安裝路徑與 `ilo-ven`/`VEN_NONPRIV_USER`；`deactivate`（不卸載、還原原生防火牆）vs `unpair`（卸載）；unpair 的 `recommended/saved/open/unmanaged` 選項；Compatibility Check 僅 Idle 可用、紅/黃/綠分級、須 Idle 才出現 Compatibility Report 標籤、可 Export；憑證匯入指令（update-ca-trust / update-ca-certificates / Windows 本機電腦層）；解除安裝後查核（資料目錄、服務名、ILO-FILTER 規則、AIX installp 順序）。
